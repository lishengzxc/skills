# 图像生成、视频生成与3D生成对比

百炼平台提供覆盖图像、视频和3D模型的完整AIGC内容生成能力。三类生成API在输入方式、调用模式、模型生态和计费策略上存在显著差异。本文从开发者技术选型的角度，对三者进行系统化对比，帮助您根据业务场景快速选择合适的生成方案。

> 各方案的完整技术文档请参见：[[image-generation]]、[[video-generation-api]]、[[3d-generation]]。

---

## 核心维度对比

| 维度 | 图像生成 | 视频生成 | 3D生成 |
|------|---------|---------|--------|
| **输入格式** | 文本提示词、参考图片（URL/Base64） | 文本提示词、图片（首帧/尾帧/参考图）、音频、视频 | 文本提示词、单张图片URL、多图数组（4视角） |
| **输出格式** | PNG 图片（URL） | MP4 视频（URL） | GLB 3D模型文件 + 预览渲染图（URL） |
| **输出分辨率/规格** | 512×512 ~ 4K（因模型而异） | 480P / 540P / 720P / 1080P | 最高200万面（Tripo-H3.1）；最高2万面（Tripo-P1.0） |
| **支持模型数量** | 丰富：千问、万相、Z-Image、可灵等多系列 | 丰富：万相、HappyHorse、PixVerse、可灵、Vidu 等 | 有限：Tripo-H3.1、Tripo-P1.0 |
| **调用模式** | **同步 + 异步**（新版模型支持同步） | **仅异步**（创建任务 → 轮询结果） | **仅异步**（创建任务 → 轮询结果） |
| **API 端点（北京）** | `https://dashscope.aliyuncs.com/api/v1/services/aigc/...` | `https://dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/video-synthesis` | `https://dashscope.aliyuncs.com/api/v1/services/aigc/video-generation/3d-generation` |
| **必需请求头** | `Authorization`、`Content-Type`（同步调用无需 Async 头） | `Authorization`、`Content-Type`、`X-DashScope-Async: enable` | `Authorization`、`Content-Type`、`X-DashScope-Async: enable` |
| **SDK 支持** | DashScope Python / Java SDK（大部分模型） | DashScope Python / Java SDK（部分模型） | HTTP API |
| **task_id 有效期** | 24小时（异步模式） | 24小时 | 24小时 |
| **结果链接有效期** | 未特别限制（建议及时下载） | 未特别限制（建议及时下载） | **2小时**（需及时下载） |
| **支持地域** | 北京、新加坡、弗吉尼亚（因模型而异） | 北京、新加坡、弗吉尼亚、法兰克福（因模型而异） | **仅北京** |
| **典型生成耗时** | 秒级（同步）~ 数十秒（异步） | 数十秒 ~ 数分钟 | 数十秒 ~ 数分钟 |

## 功能覆盖对比

| 功能场景 | 图像生成 | 视频生成 | 3D生成 |
|---------|---------|---------|--------|
| 文本生成 | ✅ 文生图 | ✅ 文生视频 | ✅ 文生3D |
| 图片驱动 | ✅ 图生图、风格迁移、参考图生图 | ✅ 图生视频、首尾帧生视频、参考生视频 | ✅ 单图/多图生3D |
| 内容编辑 | ✅ 局部重绘、去水印、扩图、超分、上色 | ✅ 视频编辑、视频换人、口型替换 | ❌ 不支持 |
| 人像/数字人 | ✅ 人像重绘、虚拟模特、AI试衣 | ✅ 数字人、舞动人像、悦动人像 | ❌ 不支持 |
| 文字处理 | ✅ 文字渲染、图像文字翻译 | ❌ 不支持 | ❌ 不支持 |
| PBR材质 | — | — | ✅ 支持PBR材质输出 |

## 计费方式对比

| 计费维度 | 图像生成 | 视频生成 | 3D生成 |
|---------|---------|---------|--------|
| **计费单位** | 按张计费 | 按任务/时长计费 | 按任务计费 |
| **免费额度** | 部分模型提供免费体验额度 | 部分模型提供免费体验额度 | 需开通后按量付费 |
| **价格示例** | 0.06~0.18元/张（因模型功能而异） | 因模型和时长/分辨率而异 | 因模型而异 |
| **付费模式** | 按量后付费 | 按量后付费 | 按量后付费 |

> 具体价格请以[百炼控制台](https://bailian.console.aliyun.com/cn-beijing?tab=model#/model-market/all)模型详情页为准。

## 协议与调用差异

### 新旧版协议

三类 API 都在经历协议升级，开发者需注意版本差异：

| 协议版本 | 图像生成 | 视频生成 | 3D生成 |
|---------|---------|---------|--------|
| **新版协议** | 千问系列使用 `messages[].content[]` 格式 | wan2.7 使用 `media` 数组传入多模态素材 | 使用 `input.[[prompt|prompt]]` / `input.image` / `input.images` |
| **旧版协议** | 万相V1等使用独立字段 | wan2.6及更早使用 `img_url`、`reference_urls` 等字段 | — |
| **建议** | 新项目使用千问系列或万相2.7 | 新项目使用 wan2.7 系列 | 使用当前版本即可 |

### 轮询建议

| 生成类型 | 建议轮询间隔 | 说明 |
|---------|-------------|------|
| 图像生成（异步） | 3~5秒 | 图像生成通常较快完成 |
| 视频生成 | 5~15秒 | 视频生成耗时较长，避免频繁轮询 |
| 3D生成 | 15秒 | 官方推荐间隔，查询接口默认 RPS 为 20 |

## 适用场景建议

### 选择[[image-generation]]（图像生成），如果您需要：

- **营销物料制作**：海报、Banner、商品主图等静态视觉内容
- **电商场景**：虚拟模特试穿、商品背景替换、鞋靴展示
- **内容创作**：插画生成、风格迁移、图文混排设计
- **图像后处理**：去水印、超分辨率、局部重绘、图像扩展
- **多语言场景**：图像文字翻译（保留原始排版）
- **实时交互**：需要同步返回结果、低延迟的应用场景

### 选择[[video-generation-api]]（视频生成），如果您需要：

- **短视频内容生产**：基于文本或图片自动生成短视频片段
- **数字人/虚拟主播**：基于肖像照片+音频生成说话、唱歌视频
- **视频编辑增强**：风格重绘、视频换人、口型同步
- **动画制作**：将静态图片转化为动态视频（图生视频）
- **创意表达**：表情包生成、舞蹈视频生成

### 选择[[3d-generation]]（3D生成），如果您需要：

- **3D资产快速生产**：游戏、AR/VR 场景中的3D道具和模型
- **工业设计预览**：从概念文字或参考图快速生成3D原型
- **电商3D展示**：商品3D模型生成，支持360°展示
- **建筑/室内设计**：从描述文字或图片生成3D场景元素
- **需要PBR材质**：生成具有物理渲染材质的高质量3D模型

## 组合使用建议

三类生成能力可以组成端到端的创作流水线：

```
文本提示词
  ├─→ 图像生成 ──→ 图生视频 ──→ 成品短视频
  ├─→ 图像生成 ──→ 单图/多图生3D ──→ 3D模型资产
  └─→ 图像生成 ──→ 图像编辑（精修）──→ 最终图片素材
```

| 组合流水线 | 说明 |
|-----------|------|
| **文生图 → 图生视频** | 先用图像生成获得关键帧，再用视频生成制作动态内容 |
| **文生图 → 图生3D** | 先生成多视角参考图，再通过多图生3D得到高质量模型 |
| **图像编辑 → 图生视频** | 先对素材图精修（去水印、风格迁移），再生成视频 |
