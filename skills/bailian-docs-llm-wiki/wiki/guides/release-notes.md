# release notes

本页汇总百炼平台的模型上下架动态与平台功能更新记录，帮助开发者快速了解可用模型变化、新功能上线及计费调整等关键信息。内容来源于平台功能更新日志和模型上下架公告，按逻辑模块组织以便查阅。

### 视频与多媒体模型

平台大量引入视频生成类模型（文生视频、图生视频、参考生视频、视频编辑），主要供应商包括：

- **万相 2.7**：文生视频（wan2.7-t2v）、图生视频（wan2.7-i2v）、参考生视频（wan2.7-r2v）、视频编辑（wan2.7-videoedit）
- **Vidu**：Q3/Q2 系列，覆盖文生视频、首帧/首尾帧生视频、参考生视频
- **爱诗 PixVerse**：v6/C1 系列，支持智能分镜与打斗特效强化
- **HappyHorse**：支持有声视频生成，720P/1080P
- **可灵 V3**：图像生成与视频生成

## 平台功能更新

以下为平台核心功能的迭代记录，详细时间线见 [模型平台功能更新](../../raw/model-user-guide/release-notes/model-release-notes.md)。

### 模型观测与监控

| 时间 | 功能 |
|------|------|
| 2025-01 | 新增模型观测能力，支持性能监测和问题定位 |
| 2025-04 | 高级监控模式：分钟级数据刷新，4xx/5xx 分类统计 |
| 2025-06 | 告警与通知功能 |
| 2025-11 | 支持查看模型推理日志（历史对话内容） |

### 模型调优与部署

- **DPO 偏好训练**（2025-09）：Qwen3-32B/14B/8B 及 Qwen2.5-72B/32B/14B/8B 支持，可降低幻觉
- **VL 模型调优**（2025-08）：Qwen2.5-VL-72B/32B/7B 支持 SFT 调优与部署
- **模型单元部署**（2025-10）：按时间计费，灵活调整性能，高稳定性，可预测成本
- **按调用量计费部署**（2024-12）：支持 Qwen2.5 多种规格调优后模型

### 模型评测

- 排行榜功能：多模型多维度（BLEU、ROUGE 等）横向对比
- 多种评估器：字符串匹配、文本相似度、模型打分、人工分类等
- 自动化评测（2024-08 上线）

### 数据处理

- 画布编排（2024-11）：灵活组合清洗与增强节点
- 数据增强（2024-06）：参数配置与 [[prompt|prompt]] 配置
- 算子类型：毒性消除、敏感词过滤、去重、去敏感信息等

### Context Cache（上下文缓存）

2024-12 上线，减少重复运算、提升响应速度、降低使用成本。详见 [[context-cache]]。

> **注意**：根据 [模型上下架与更新](../../raw/model-user-guide/release-notes/newly-released-models.md) 记录，deepseek-v4-pro 的 `cached_token` 单价已调整为 1 元/百万 token（2026-04-29），而功能更新文档中仅提及初期支持 qwen-plus 模型。当前支持缓存的模型范围已大幅扩展，请以模型列表页面为准。

### OpenAI 接口兼容

- **Batch 调用**（2024-08）：批量请求，24 小时内异步返回，费用为实时调用的一半
- **Batch 任务通知**（2024-12）：支持 Callback 回调和 EventBridge 消息
- **Vision 调用**（2024-08）：调整 API-KEY/BASE_URL/model 即可使用视觉模型

- 新增免费额度和用量统计看板（2025-12）

## 限制与注意事项

- **模型下线机制**：平台有明确的模型下线规则及通知流程，使用快照版本的开发者应及时关注迁移建议。参见 [[model-depreciation]]。
- **部分模型限制**：
  - qwen3.7-max-preview、qwen3.6-max-preview 仅支持纯文本输入，不支持图像与视频输入
  - qwen3.7-max 仅支持思考模式
- **限流扩容**：支持自定义申请限流扩容，可通过模型广场详情页提交申请
- **区域限制**：中国内地部署范围的推理计算资源仅限于中国内地，目前支持华北2（北京）地域

> **注意**：两篇文档的时间线存在差异——功能更新文档覆盖 2024-2025 年的平台能力迭代，而模型上下架文档主要记录 2026 年的新模型发布。开发者应结合两者获取完整视图。
