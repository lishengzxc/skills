# plug in

插件（Plugin）是百炼平台中用于拓展大模型能力的工具集合，解决大模型无法获取实时信息、精确计算、图像生成等局限性。一个插件下可包含多个工具（API），每个工具实现特定功能。百炼支持官方插件、三方插件和自定义插件三种类型。

## 支持的模型

根据 [插件概述](../../raw/application-user-guide/plug-in/plug-in-overview.md)，以下模型支持插件调用：

| 模型 | 模型标识符 |
|------|-----------|
| 通义千问-Turbo | `qwen-turbo` |
| 通义千问-Plus | `qwen-plus` |
| 通义千问-Max | `qwen-max` |
| 通义千问VL-Max | `qwen-vl-max` |
| 通义千问VL-Plus | `qwen-vl-plus` |

> **注意**：各模型对插件的兼容性可能有差异，最新兼容性状态以控制台实际执行结果为准。模型详情参见 [[models]]。

## 插件类型

### 官方插件

组件广场中预置的官方插件，无需配置输入输出参数即可直接调用。详见 [官方和第三方插件](../../raw/application-user-guide/plug-in/plugins.md)。

| 插件名称 | 工具 ID | 说明 | 计费 |
|---------|---------|------|------|
| Python 代码解释器 | `code_interpreter` | 执行 Python 代码片段（数学计算、数据分析与可视化） | 免费 |
| 计算器 | `calculator` | 复杂数学计算 | 免费 |
| 图片生成 | `text_to_image` | 基于文本生成图片 | 限时免费，需申请开通 |
| 夸克搜索 | `quark_search` | 搜索实时信息（仅支持网页标题、关键词和摘要，不支持访问网页详情） | 限时免费，需申请开通 |
| 生成二维码 | `generate_qrcode` | 根据链接生成二维码 | 免费 |
| GitHub 搜索 | `github_search` | 搜索 GitHub 项目列表（不支持访问项目详情） | 免费 |

> **注意**：Python 代码解释器不支持对外访问网络及上传本地文件，可用依赖列表有限（包括 matplotlib、pandas、scipy、numpy 等常用库）。

支持在同一任务中组合调用多个插件，例如同时使用夸克搜索 + 图片生成 + 生成二维码完成复合任务。

### 三方插件

涵盖商业服务、图像视频、学习教育等领域，经过效果测试。需先开通（免费试用或购买套餐）后直接调用，无需额外配置。

### 自定义插件

当官方和三方插件无法满足需求时，可创建自定义插件集成所需 API。详见 [自定义插件](../../raw/application-user-guide/plug-in/custom-plug-ins.md)，工作流程为：

1. **创建/导入插件**：定义插件基础信息（名称、描述、URL、鉴权配置），或从云市场导入
2. **添加工具**：配置工具路径、请求方法、输入/输出参数
3. **调试与发布**：在线测试 API 连通性，发布后方可使用
4. **在应用中使用**：关联到 [[single-agent-application]] 或通过 API 调用

## 插件调用机制

调用插件的本质是调用插件下的工具。百炼支持以下三种方式调用插件：

- **[[single-agent-application]]**：在智能体编排页面添加插件工具（最多 10 个），大模型根据用户输入自动判断是否调用
- **[[workflow-application]]**：将插件作为工作流节点，按编排方式执行，而非由大模型主动规划
- **[[assistant-api]]**：通过 API 中的 `tools` 参数调用工具

通过智能体或 Assistant API 调用时，大模型根据**用户输入**、**工具名称**和**工具描述**判断是否需要调用工具。需要时自动选择合适工具并将结果合并生成最终输出；不需要时直接生成结果。

## 关键参数与配置

### 自定义插件参数

**插件级配置**：
- **插件名称**：具有语义的名称，帮助大模型理解插件功能
- **插件描述**：功能和使用场景说明，影响大模型是否调用该插件
- **插件 URL**：插件的访问域名
- **鉴权配置**（可选）：支持服务级鉴权和用户级鉴权，鉴权信息可放在 Header 或 Query 中，Token 类型支持 basic / bearer / appcode

**工具级配置**：
- **工具路径**：相对于插件 URL 的路径，以 `/` 开头
- **请求方法**：GET 或 POST
- **提交方式**：`application/json` 或 `application/x-www-form-urlencoded`
- **输入参数**：传参方式分为「大模型识别」（从用户输入提取）和「业务透传」（通过 `biz_params` 和 `user_defined_params` 外部传入）
- **输出参数**：大模型据此筛选和重组 API 返回结果
- **高级配置**：提供调用示例，减少模型的漏召回和误召回

### 工具 ID

工具 ID 用于 API 调用时标识具体工具。可在插件详情页的「插件工具」部分获取。

## 使用方式

### 控制台使用

1. **插件页面添加**：在插件页面将工具添加至智能体应用（官方插件需与应用在同一业务空间）
2. **应用管理页面添加**：在智能体或工作流应用编排页面添加插件
3. **发布为 MCP 服务**（自定义插件）：将插件发布为 [[mcp]] 服务后，在智能体的 MCP 区块中添加

### API 调用

- 通过 [[assistant-api]] 的 `tools` 参数调用
- 如插件存在业务透传参数或用户级鉴权，需通过 `biz_params` 传递相关信息

## 授权与权限

- 首次访问插件页面需授权 `AliyunServiceRoleForSFMAccessCloudAPI` 角色
- 主账号可直接在插件页面授权
- RAM 用户（子账号）需主账号先授予 `ram:CreateServiceLinkedRole` 权限（ServiceName: `cloundapi-access.sfm.aliyuncs.com`）
- 在子业务空间调用官方插件时，需先为子业务空间单独授权

## 限制和注意事项

- 智能体应用最多添加 **10 个工具**
- 官方插件只能与**同一业务空间**的智能体应用关联
- 删除插件会删除其下所有工具，且关联应用会失效，**不可撤回**
- 修改插件的 URL、Header、鉴权信息后需重新测试并发布工具
- 自定义插件中 Object 类型参数的子属性不能为空；GET 请求不支持 Object 类型输入参数
- 从云市场导入的插件，系统自动填充参数信息，但可能存在缺失，发布前需检查

> **注意**：夸克搜索插件与 [[enable-search]]（联网搜索）虽然都基于夸克搜索，但行为不同。夸克搜索插件直接调用并以文本返回搜索结果；联网搜索（`enable_search`）则让模型尝试利用互联网信息丰富生成内容，不会完全依赖搜索结果。

### 常见错误码

| 错误码 | 说明 | 解决方案 |
|--------|------|---------|
| 130040 | 参数描述缺失 | 补充参数描述后重新发布 |
| 130022 | 保存工具信息异常 | 检查 Object 类型子属性是否为空，或 GET 请求下是否误用了 Object 类型 |
