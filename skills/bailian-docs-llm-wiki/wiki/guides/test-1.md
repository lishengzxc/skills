# test 1

阿里云百炼平台的计费体系涵盖模型推理调用、模型训练、模型部署等多个维度，并提供免费额度、节省计划、资源包等多种成本优化手段。本文整合了平台计费相关的核心信息，帮助开发者快速理解费用构成、选择最优计费方案，并有效管控成本。

---

## 计费模式概览

百炼平台的费用主要来自以下三类场景：

| 场景 | 计费方式 | 说明 |
|------|---------|------|
| **模型推理（调用）** | 按 Token 用量（按量后付费） | 输入/输出 Token 分别计价，部分模型支持[[阶梯计费]] |
| **模型训练** | 按训练 Token 计费 | 费用 = Token 总数 × 循环次数 × 单价 |
| **模型部署** | 按使用时长 / 按 Token 用量 / 包月预付费 | 支持预置吞吐、模型单元等多种部署模式 |

详细的推理单价可参考 [模型调用价格](../../raw/model-user-guide/test-1/model-pricing.md)，训练与部署计费规则见 [模型训练与部署计费](../../raw/model-user-guide/test-1/model-training-and-deployment-billing.md)。

## 免费额度

首次开通阿里云百炼（**仅中国内地版**）时，系统自动发放各模型的新人免费额度。关键规则：

- **有效期**：30～90 天（自 2025 年 9 月 8 日起新开通用户为 90 天）。
- **适用范围**：仅抵扣**实时推理**费用，不支持 Batch 调用、[[上下文缓存]]、[[模型调优]]、[[模型部署]]及自定义模型。
- **共享机制**：主账号与 RAM 子账号共享同一免费额度池。
- **用完即停**：建议开启「免费额度用完即停」功能，额度耗尽时返回错误码 `AllocationQuota.FreeTierOnly`，防止意外扣费。

> **注意**：全球、国际、欧盟、美国等非中国内地部署范围的模型**无免费额度**。同时请注意 `qwen-max` 与 `qwen-max-latest` 的免费额度不共享，使用前应确认具体模型版本的额度情况。

更多细节参见 [新人免费额度](../../raw/model-user-guide/test-1/new-free-quota.md)。

## 模型调用价格要点

### 阶梯计费

部分模型实行阶梯计费——单价由**单次请求的输入 Token 总量**决定，该请求所有 Token 按对应阶梯统一结算。例如千问 Max（`qwen3-max`）分 0\~32K、32K\~128K、128K\~256K 三档。

### Batch 调用与上下文缓存

- **Batch 调用**：支持的模型输入/输出单价按实时推理价格的 **50%** 计费。
- **上下文缓存**：仅输入 Token 享有折扣。
- 两者**不能同时生效**。

### 地域差异

同一模型在不同部署范围（中国内地、全球、国际、欧盟、美国）下的单价差异显著。例如 `qwen-plus` 中国内地输入单价为 0.8 元/百万 Token，国际（新加坡）则为 2.936 元/百万 Token。

## 成本优化方案

百炼提供三种预付费优惠方案，抵扣优先级为：**免费额度 > 资源包 > 其他模型节省计划 > AI 通用型节省计划 > 按量付费**。

### AI 通用型节省计划（推荐）

- 承诺每月消费金额（1000 元起），换取阶梯折扣，最高 **5.3 折**。
- 覆盖阿里直供全部模型（A/B/C 三类），支持跨模型抵扣。
- 承诺周期：3/6/12/24 个月，支持全预付和零预付（需白名单）。
- **每月额度独立，当月未用完自动清零，不可累积**。
- 抵扣范围包括：模型调用、工具调用（Function Call、联网搜索等）、上下文缓存、批量推理。不支持模型调优/部署、MCP 广场。

> **注意**：C 类模型（如 DeepSeek、Kimi、GLM 等三方模型）当前在 AI 通用型节省计划中**无折扣**。

### 其他模型节省计划

针对特定模型系列（万相、千问语音、向量排序等）的固定金额节省计划。折扣通常不如 AI 通用型，适用于用量集中的场景。不支持抵扣工具调用、上下文缓存、批量推理等费用。

### 资源包

预购具体 Token 数量，用于抵扣特定模型的实时推理用量。购买后立即生效，到期自动作废。

详细方案对比和购买链接见 [节省计划与资源包](../../raw/model-user-guide/test-1/savings-plan-and-resource-package.md)。

## 账单查询与成本管理

### 出账周期

- **大模型推理**：分钟级出账（调用后约 2～10 分钟）。
- **其他服务**（批量推理/训练/知识库等）：小时级出账。

### 账单字段解读

账单中 `实例 ID（出账粒度）` 字段格式为：`ApiKeyID;业务空间ID;模型名称;输入输出类型;调用渠道;免费额度用完即停标识`。通过该字段可追溯具体调用来源。调用渠道 `app` 表示 API 调用，`bmp` 表示控制台体验。

### 分账管理

通过对**业务空间**绑定标签，可实现按部门/项目维度的费用分摊。分账账单 T+1 天生效。

### 欠费影响

账户可用额度 < 0 时视为欠费。欠费后：
- 仍有免费额度或节省计划/资源包额度的商品可继续使用，否则停服。
- [[Coding Plan]] 和 Token Plan 套餐额度独立于账户余额，欠费不影响使用，但会导致自动续费失败。

## 模型训练与部署计费要点

### 训练

- **文本模型**：费用 =（训练数据 Token + 混合数据 Token）× 循环次数 × 单价。支持 Qwen3.5/3/2.5 系列及千问 VL 系列。
- **视频模型（万相）**：费用按训练 Token 总量计算，与视频时长、max_pixels、n_epochs 相关。

### 部署

| 模式 | 计费公式 | 适用场景 |
|------|---------|---------|
| 预置吞吐（按时长） | 使用时长 × TPM × 单价 | 需要稳定吞吐的在线服务 |
| 模型单元（按时长） | 使用时长 × 单元数 × 单价 | 支持 PD 分离模式降低首 Token 延迟 |
| 按 Token 使用量 | 输入 Token × 单价 + 输出 Token × 单价 | 仅限 SFT 高效训练后的自定义模型 |

> **注意**：预置吞吐模式下，当输入超过最长 Token 限制或超出购买的 TPM 时，调用会**自动降级为按量付费**，此时推理性能可能下降，API 响应 Header 会包含 `x-dashscope-ptu-overflow:true`。

## 停止计费

如需彻底停止产生费用：

1. **删除 API-Key**：避免意外 API 调用。
2. **下线已部署模型**：包月预付费需额外到退订管理页面退订。
3. **关闭 Coding Plan 自动续费**：到期自动停止，无需手动取消。
4. **设置消费预警**：通过[高额消费预警](https://usercenter2.aliyun.com/home/alarm-threshold)设置日账单阈值。

---

## 限制与注意事项

- 免费额度数据为**分钟级更新**，需手动刷新页面，显示可能滞后于实际消耗。
- 按量付费采用「预占+月结」模式，**非实时扣款**，次月初统一结算。
- 模型调用记录需**调用完成约一小时后**才可在模型监控页面查询，高峰期可能有小时级延迟。
- 后付费场景账户欠费后，已部署资源将**保留并继续计费 24 小时**，之后自动释放。
