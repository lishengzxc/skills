# llm application

阿里云百炼平台提供三种核心应用构建模式——智能体（Agent）、工作流（Workflow）和高代码应用，用于突破大模型在私有知识处理、实时信息获取、固定流程执行和复杂任务规划等方面的原生局限。通过集成[[knowledge-base]]检索增强、外部工具调用、[[mcp]]服务和记忆等能力，开发者可以快速构建解决真实业务问题的 AI 应用。

## 应用类型与选型

百炼提供三种应用类型，适用于不同开发人群和业务场景。详细对比参见 [应用类型介绍](../../raw/application-user-guide/llm-application/application-introduction.md)。

| 对比维度 | 智能体（Agent） | 工作流（Workflow） | 高代码应用 |
|---------|---------------|-------------------|-----------|
| 开发方式 | 自然语言配置（零代码） | 可视化节点编排（低代码） | Python 编码 |
| 核心特点 | AI 自主决策、动态规划 | 预定义流程精确控制 | 完全由代码控制 |
| 适合人群 | 业务人员、产品经理 | IT 运维、业务分析师 | AI 工程师、开发者 |
| 开发门槛 | 低 | 中 | 高 |

**选型建议：**

- **智能体**：适合开放式对话，如智能客服、知识问答、旅行规划等需要模型自主决策的场景。
- **工作流**：适合固定流程自动化，如报告生成、订单处理、数据标注等需要稳定可控执行链路的场景。
- **高代码应用**：适合部署私有算法、集成复杂系统、构建专业级 AI 后端服务等需要深度定制的场景。

## 智能体应用（Agent）

### 新版智能体（Agent 2.0）

新版智能体将知识库、MCP 等多种能力统一为工具，由模型自主思考和规划调用顺序，支持完整的"规划-执行-反思"链路展示。详见 [新版智能体应用](../../raw/application-user-guide/llm-application/new-single-agent-application.md)。

**与旧版（Agent 1.0）的关键区别：**

- **旧版**：知识库检索先行，再决策是否调用其他工具；缺乏任务规划，无法完成复杂研究任务。
- **新版**：知识库与 MCP 统一作为工具，智能体自主规划调用时机和顺序；能完整展示决策过程。

> **注意**：旧版与新版基于不同技术架构，不支持直接升级或迁移。如需使用新版，需重新创建应用。

### 核心能力配置

#### 模型选择

推荐选用具备强工具调用能力的模型（如 `千问-Max` 系列）。可配置参数包括：

- **最长回复长度**：模型生成长度限制（不含提示词）
- **temperature**：控制生成随机性，数值越高随机性越强
- **enable_thinking**：是否开启思考模式（仅支持思考模式的模型可配置）

#### 系统提示词

定义智能体角色、行为指令与能力边界。编写要点：

- 定义角色及专业知识
- 指定输出格式（结构、长度、风格）
- 设置约束条件（避免的内容、需遵守的规则）
- 引导工具使用（明确工具名称和使用时机）

支持通过自定义变量实现动态提示词。

#### 知识库（RAG）

连接外部[[knowledge-base]]，基于私有数据回答问题。新版智能体中知识库作为工具由智能体自主调用，支持通过标签限定查询范围以提升检索精准度。

> **注意**：从知识库检索到的文本会占用模型上下文窗口，需根据实际情况调整检索策略和文本长度。

#### MCP 工具

外部工具均以 [[mcp]] 协议接入，包括官方 MCP 和自定义 MCP 服务。智能体可在多步推理中动态调用。旧版[[plugin]]也支持一键转换为 MCP 服务。

#### 记忆

- **短期记忆**：支持 0-30 轮上下文（0 代表不传递历史记录）
- **长期记忆**：旧版智能体支持，新版计划在后续迭代中支持

#### 预解析文件

控制上传文件的处理方式：开启后使用预置解析器处理文档/图像/视频/音频；关闭后仅传递文件 URL 给智能体。

> **注意**：千问-VL 系列模型具备多模态能力，即使关闭预解析也能直接解析图片和视频文件。

### 文件问答

智能体应用支持三种文件处理模式，详见 [文件问答](../../raw/application-user-guide/llm-application/file-q-a.md)：

| 模式 | 适用场景 | 特点 |
|------|---------|------|
| **全文引用** | 文档总结、全文翻译、风格润色 | 简单直接，受限于上下文长度 |
| **切片检索（RAG）** | 长文档问答、精确定位信息 | 能处理超长文件，依赖检索策略 |
| **自定义处理** | 图片风格转换、视频分析等 | 灵活强大，依赖配置的工具 |

**支持的文件格式：**

- 文档：`.doc`、`.docx`、`.pdf`、`.md`、`.txt`、`.xls`、`.xlsx`、`.ppt`、`.pptx` 等
- 图片：`.png`、`.jpg`、`.jpeg`、`.bmp`、`.gif`
- 视频：`.mp4`、`.mkv`、`.avi`、`.mov` 等
- 音频：`.mp3`、`.wav`、`.flac`、`.aac` 等

单个会话最多上传 10 个文件，单文件不超过 10MB。超过 10MB 可使用文件上传 API。

### 运行与调试

新版智能体以卡片流展示决策过程：

1. **思考（Thinking）**：展示模型推理逻辑（仅支持思考模式的模型）
2. **工具调用**：记录具体的工具调用入参和返回结果

通过 **ReAct 最大轮次**（1-50）限制单次会话中工具调用的最大次数。

## 工作流应用

工作流通过可视化节点编排，将复杂任务串联成有序执行步骤。详见 [工作流应用](../../raw/application-user-guide/llm-application/workflow-application.md)。

### 核心节点

| 节点类型 | 用途 |
|---------|------|
| 开始/结束 | 定义输入/输出参数结构 |
| 大模型 | 调用 LLM 进行推理和生成 |
| 意图分类 | 识别用户意图并路由到不同分支 |
| 智能体群组 | 编排多个子智能体协作完成任务 |
| 变量处理 | 处理和转换流程中的变量 |

### 关键特性

- **会话变量**：全局变量，在工作流全生命周期内记录参数，可在各节点中引用
- **记忆**：支持本节点缓存和自定义缓存（全局聊天内容记忆）
- **预置变量**：`query`（用户输入）、`historyList`（对话历史）、`imageList`（图片列表）

### 典型场景

- 诈骗信息识别、智能导购、日程管理
- 自动化报告生成、多步骤审批流
- 数据标注工作流

## 高代码应用

面向专业开发者，支持基于 Python 项目结构部署 AI 后端服务。详见 [高代码应用](../../raw/application-user-guide/llm-application/rich-code-application.md)。

### 部署方式

| 方式 | 适用场景 |
|------|---------|
| **Serverless Function**（默认） | 低负载、无状态、快速拉起，部署花销低 |
| **K8s** | 高性能、有状态、长程任务，需开通 ACK 容器服务 |

### 核心能力

- 一站式 MCP 工具接入（知识库、工作流、插件等）
- 自定义前端（直接体验、交互卡片、基于 Spark Design 的 WebUI）
- 企业级运维：自动化运维、可观测、日志服务、API 网关
- 应用模板：基础对话 Agent、工具调用 Agent、深度研究 Agent

### 应用管理

- **部署**：代码包更新、资源规格调整、运行日志查看
- **工具**：MCP 服务关联
- **网关**：自定义域名、路由配置、Token 鉴权
- **前端**：三种体验方式（直接体验、交互卡片、WebUI）

## 发布与 API 调用

所有应用类型都需要先**发布**才能进行 API 调用或集成。

- **智能体应用**：默认调用频率上限 100 次/分钟
- **工作流应用**：发布后通过工作流应用 API 调用
- **高代码应用**：通过触发器或网关路由访问

> **注意**：如果应用由 RAM 账号创建，发布前需确认已拥有 `ram:CreateServiceLinkedRole` 权限。

## 计费说明

| 计费项 | 说明 |
|-------|------|
| 模型调用 | 按模型类型、输入/输出 Token 数量计费 |
| 知识库 | 按量付费；召回文本会增加模型输入 Token |
| MCP/插件 | 部分官方 MCP 按模型调用计费；第三方 API 费用由第三方收取 |
| 长期记忆 | 数据存储不收费；记忆体内容占用的 Token 暂不计费 |
| 高代码应用 | 函数计算、API 网关、存储等按阿里云账单计费 |

仅创建应用不收费，调用时才产生费用。

## 支持的模型

智能体应用支持千问系列模型和自定义部署模型，包括：

- **文本生成**：千问-Max、千问-Plus、千问-Turbo、千问-Long、千问3-Coder-Plus、QwQ 系列、DeepSeek 等
- **视觉理解**：千问-VL-Max、千问-VL-Plus、千问-VL-OCR

> **注意**：数据更新可能存在延迟，模型支持情况以智能体应用内显示为准。

## 限制和注意事项

- 自定义插件超时限制为 **5 秒**
- 文件问答 API 与所属智能体共享调用配额（默认 100 次/分钟）
- 上传文件仅在当前会话有效，刷新或关闭页面将导致文件丢失
- 通过文件上传 API 上传的文件有效期通常为 **24 小时**
- API 调用时**无法**动态切换文件处理模式（全文引用/切片检索/自定义处理）
- 应用对外提供服务需遵守《生成式人工智能服务管理暂行办法》，完成应用合规备案
- 高代码应用的部署地域应与网关所在地域相同
