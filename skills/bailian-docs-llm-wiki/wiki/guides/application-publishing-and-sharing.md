# application publishing and sharing

百炼平台支持将已构建的智能体或工作流应用通过多种渠道发布和分享，包括网页链接、钉钉/微信集成、UI 应用、音视频互动以及组件化复用。开发者可根据业务场景选择合适的发布方式，将 AI 能力快速集成到实际产品中。发布前需确保应用已完成构建并至少发布过一次。

## 发布渠道概览

百炼应用支持以下五种主要发布方式：

| 发布方式 | 适用应用类型 | 说明 |
|---------|------------|------|
| 官方网页版 | 仅智能体应用 | 生成分享链接，默认有效期 7 天 |
| UI 应用（魔笔） | 智能体、工作流 | 通过 [[ui-designer]] 可视化搭建自定义界面 |
| 钉钉机器人 | 智能体 | 集成为钉钉群聊机器人 |
| 微信公众号 | 智能体 | 集成为微信公众号 AI 机器人 |
| 组件 | 智能体、工作流 | 发布为可复用模块，供其他应用接入 |
| 音视频实时互动 | 智能体、工作流（图文对话类） | 通过语音/视频与应用实时交互 |

详细的分享流程参见 [分享智能体应用](../../raw/application-user-guide/application-publishing-and-sharing/share-an-application.md)。

## 网页分享

### 官方网页版

在应用的**发布渠道**页面点击**官方网页版 > 创建**即可生成分享链接，默认有效期 7 天。持有链接的阿里云用户均可访问，所有调用费用由应用创建者账号承担。可选开启**应用观测**以统计 Token 消耗。

> **注意**：官方网页版仅支持智能体应用，不支持工作流应用。

### UI 应用

通过 [[ui-designer]] 可以构建自定义界面的网页应用。平台提供四种预置模板（智能出行助手、智能体门户、AI 基础对话、企业 AI 知识库 Lite）及空白模板。详细操作参见 [UI设计器](../../raw/application-user-guide/application-publishing-and-sharing/ui-designer.md)。

关键要点：

- 百炼应用、[[api-key]] 和 UI 设计需归属**同一业务空间**
- **开发环境**免费发布，有效期 24 小时；**生产环境**长期有效，需订阅付费套餐
- 工作流应用如配置了文件类型自定义参数，需在 UI 设计器中指定 `{{{file_name:files[0]}}}`

## 第三方平台集成

### 钉钉机器人

集成流程：

1. 在百炼完成 AppFlow 授权（首次需授权 SLR 和 API-KEY 加密传输）
2. 在[钉钉开放平台](https://open-dev.dingtalk.com/)创建应用，获取 Client ID 和 Client Secret
3. 创建消息卡片模板，获取模板 ID，并授予 `Card.Streaming.Write` 和 `Card.Instance.Write` 权限
4. 在百炼填入配置信息完成创建，将回调地址配置到钉钉机器人的消息接收地址

> **注意**：钉钉机器人消息接收模式必须选择 **HTTP 模式**，选择 Stream 模式会导致无法返回消息。创建钉钉应用需要开发者权限。

### 微信公众号

集成流程：

1. 完成 AppFlow 授权（如已在钉钉步骤中授权则无需重复）
2. 获取微信公众号的 **开发者 ID（AppID）**
3. 在百炼选择或新建微信凭据，完成配置

## 组件化发布与复用

智能体或工作流应用可发布为组件，供其他应用作为模块接入使用。完整的组件开发和使用流程参见 [使用智能体或工作流作为组件](../../raw/application-user-guide/application-publishing-and-sharing/use-agent-or-workflow-as-component.md)。

### 发布组件

两种发布入口：

- 在应用编辑界面点击**发布应用**时勾选**发布应用组件**
- 在[组件管理](https://bailian.console.aliyun.com/?tab=app#/component-manage)面板点击**创建组件**

### 组件参数配置

组件预设两个系统参数（不可删除，仅可隐藏）：

| 参数 | 用途 |
|------|------|
| `query` | 传递用户输入的文本 |
| `imageList` | 传递用户输入的图像公网地址列表（仅在使用 [[vision]] 模型时有效） |

每个参数需配置：

- **别名**：对外展示的参数名称，避免命名冲突
- **参数描述**：用于模型识别时的自动推断依据
- **是否可见**：控制是否对外透出
- **传参方式**：
  - **业务透传**：接入智能体时由使用者提供，接入工作流时由上游节点提供
  - **模型识别**：接入智能体时由大模型自动推断；接入工作流时**不会**自动推断，必须从上游节点显式提供

### 接入组件

- **智能体应用**：在技能配置中选择组件，大模型根据组件描述和上下文自动判断是否调用。业务透传参数可在测试时手动填入，或通过 API 的 `biz_param` 参数传入。
- **工作流应用**：将组件节点拖入画布，手动配置输入参数并将输出传递至下游节点。支持开启[[streaming|流式输出]]。

## 音视频实时互动

仅支持图文对话类应用。配置完成后支持两种发布渠道：

- **H5/APP 扫码**：生成分享链接，设置 Token 有效时间
- **SDK 集成**：支持快速集成和开发集成两种方式

发布前需开通智能媒体服务并完成 SLR 授权。

## 限制与注意事项

1. **组件自动更新**：应用重新发布后，对应组件自动更新。
2. **避免嵌套调用**：A 调用 B、B 调用 A 会导致重复调用，功能不可用。
3. **避免多级调用**：A → B → C 的链式调用容易因最长运行时间限制而超时。
4. **费用归属**：通过分享链接产生的所有费用由应用创建者 UID 账号承担。
5. **UI 应用数据库映射**：使用已有数据库表时，表结构必须与模板内置表**完全一致**，否则会导致运行时错误。
6. **业务空间一致性**：百炼应用、API Key 和 UI 设计必须归属同一 [[workspace]]。
